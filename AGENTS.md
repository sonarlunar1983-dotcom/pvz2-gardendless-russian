# Правила разработки

Общение и документация — на русском. Для 0.16.31 использовать ветку `localization/0.16.31`, remote `fork`; перед push проверять его адрес: https://github.com/sonarlunar1983-dotcom/pvz2-gardendless-russian.git. Remote `origin` — исходный проект KRUTONIK.

Создание тега и публикация GitHub Release требуют отдельного явного одобрения пользователя. Не считать подготовку сборки или отправку рабочей ветки таким одобрением.

Основные исходники помощника находятся в `font-fixer/`. Сборочный проект `../pvz2-localization-research` читает свою копию `src/font-fixer/`: править сначала форк, затем синхронизировать и проверять различия. Снимок обновлённых средств сборки — `build-tools/research/`; условия сборки описаны в `docs/RELEASE-0.16.27.md`.

Готовые артефакты разрешено копировать в `E:\TGames\pvzge` со сверкой SHA-256. По отдельному указанию пользователя официальный архив игры также входит в локальный деплой: скачать `https://storage.pvzge.com/pvzge-0.16.31.zip` непосредственно в конечную папку и распаковать туда EXE, сверив архив и EXE с проверенной официальной поставкой. Сценарий — `build-tools/research/scripts/deploy-0.16.31.cjs`. Не запускать игру, GUI помощника и импорт; не менять сохранения и настройки. Оригинальные EXE, извлечённые ресурсы игры, сохранения, инструменты и учётные данные не включать в Git. В начале README сохранять ссылки на оригинальную игру и исходный русификатор.

Подготовленное состояние: игра 0.16.31, мод 1.3.2, Font Fixer 1.43, JS VERSION 48, шрифты 0.5. 322 файла данных, 7638 русских полей, пропусков нет. 66 JS-проверок, 10 проверок пакета, Go test/vet, ZIP, изолированные DOM-стенд и snapshot-loader. Новые DOM-окна при русском языке используют Segoe UI: оригинальный Game Default не содержит кириллицу. При отключении восстанавливаются только свойства шрифта, трансформация окна сохраняется. Тег/релиз 0.16.31 не создавать без отдельного одобрения. Старые исправления размеров и позиций сохранять; расчёт вести от сохранённой исходной базы.
