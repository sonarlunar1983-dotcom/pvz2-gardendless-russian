# Правила разработки

Общение и документация — на русском. Для 0.16.27 использовать ветку `localization/0.16.27`, remote `fork`; перед push проверять его адрес: https://github.com/sonarlunar1983-dotcom/pvz2-gardendless-russian.git. Remote `origin` — исходный проект KRUTONIK.

Создание тега и публикация GitHub Release требуют отдельного явного одобрения пользователя. Не считать подготовку сборки или отправку рабочей ветки таким одобрением.

Основные исходники помощника находятся в `font-fixer/`. Сборочный проект `../pvz2-localization-research` читает свою копию `src/font-fixer/`: править сначала форк, затем синхронизировать и проверять различия. Снимок обновлённых средств сборки — `build-tools/research/`; условия сборки описаны в `docs/RELEASE-0.16.27.md`.

Готовые артефакты разрешено копировать в `E:\TGames\pvzge` со сверкой SHA-256. Не запускать игру, GUI помощника и импорт; не менять сохранения и настройки. Оригинальные EXE, извлечённые ресурсы игры, сохранения, инструменты и учётные данные не включать в Git. В начале README сохранять ссылки на оригинальную игру и исходный русификатор.

Подготовленное состояние: игра 0.16.27, мод 1.3.1, Font Fixer 1.42, JS VERSION 47, шрифты 0.5. Старые исправления размеров и позиций сохранять; расчёт вести от сохранённой исходной базы.
