Gardendless 0.16.27 — русификатор 1.3.1, Font Fixer 1.42

Игра: https://github.com/Gzh0821/pvzg_site/releases/tag/0.16.27
Исходный перевод: https://github.com/KRUTONIK/pvz2-gardendless-russian
Наш форк: https://github.com/sonarlunar1983-dotcom/pvz2-gardendless-russian

1. Распакуйте внешний комплект. Закройте игру и старый Font Fixer.
2. Запустите PvZ2_Gardendless_Font_Fixer_1.42.exe и выберите pvzge-0.16.27.exe.
3. Запустите игру через помощник.
4. В F9 → Mods → Import ZIP импортируйте только PvZ2_Gardendless_Russian_0.16.27_preview.zip.
5. Примените обновление мода до 1.3.1 и выберите русский язык.

Внешний архив with_Font_Fixer не предназначен для импорта в игру.
Новый пакет нужен даже при установленной версии 1.3.0: изменились исходные игровые данные.
Оригинальная игра, сохранения и настройки в комплект не входят.

Переведены новые диалоги Смоломёта, тексты колод и условие уровня Водной лозы.
Помощник поддерживает новые DOM-окна сведений, обновлений, уровней сообщества
и музыкальных наборов, сохраняя все прежние правки интерфейса и шрифты 0.5.
Названия, описания и авторство пользовательских уровней не подменяются.
Документы переводятся только при точном совпадении с проверенной версией.

Проверки выполнены на данных и в отдельном браузерном стенде.
Игра и GUI помощника автоматически не запускались; вид интерфейса в игре
и фактический импорт должен проверить пользователь.
