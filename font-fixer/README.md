# Font Fixer 1.0

Утилита исправляет отображение кириллицы в Windows-версии PvZ2 Gardendless, не изменяя оригинальный `PvZ2.exe`.

## Использование

1. Полностью закройте Gardendless.
2. Запустите `PvZ2_Gardendless_Font_Fixer_1.0.exe`.
3. Укажите полный путь к оригинальному `PvZ2.exe`.
4. Настройте параметры шрифта и нажмите «Запустить игру».

Пока игра работает, параметры можно менять кнопкой «Применить». Настройки сохраняются в `%APPDATA%\PvZ2GardendlessFontFix\settings.json`.

## Сборка

Требуется Go 1.23 или новее:

```bat
build.bat
```

Готовый файл появится под именем `PvZ2_Gardendless_Font_Fixer_1.0.exe`.
