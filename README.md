# PvZ2 Gardendless — Русификатор

Русская локализация для **PvZ2 Gardendless 0.14.0** с отдельной утилитой Font Fixer 1.0 для корректного отображения кириллицы.

Переведены интерфейс, растения, зомби, Альманах, диалоги, уровни и другие игровые тексты.

## Скачать

Готовые файлы доступны на странице [последнего релиза](https://github.com/KRUTONIK/pvz2-gardendless-russian/releases/latest):

- `PvZ2_Gardendless_Russian_0.14.0.zip` — русификатор;
- `PvZ2_Gardendless_Font_Fixer_1.0.exe` — исправление отображения кириллицы.

## Установка русификатора

1. Скачайте `PvZ2_Gardendless_Russian_0.14.0.zip`.
2. Поместите архив в папку `gp-next/packs/`.
3. Запустите игру и откройте `F9 → Patcher`.
4. Нажмите `Save & Reload`, затем выберите русский язык.

## Font Fixer 1.0

1. Полностью закройте Gardendless.
2. Запустите `PvZ2_Gardendless_Font_Fixer_1.0.exe`.
3. Укажите путь к оригинальному `PvZ2.exe`.
4. Настройте шрифт при необходимости и нажмите «Запустить игру».

Настройки сохраняются автоматически. Утилита не изменяет оригинальный `PvZ2.exe`.

## Совместимость

- PvZ2 Gardendless 0.14.0
- Windows x64

Исходный код Font Fixer находится в каталоге [`font-fixer`](font-fixer/).
