# Gardendless 0.16.15

Мод 1.3.0 содержит 307 файлов данных и 7529 русских полей. Адаптация включает новые растения, колоды Далёкого будущего и музыкальные наборы. Font Fixer 1.41 добавляет кириллицу, перевод новых окон и правки размещения подписей.

Совместимость и порядок установки описаны в [README](../README.md). Данные проверены на сохранность исходных значений и порядка массивов. В рабочем проекте прошли 9 тестов пакета и 66 JS-тестов помощника, Go test/vet, проверка ZIP и чтение мода загрузчиком 0.16.15. Модальные окна проверены на локальной модели в Chromium.

Для выпуска нужны архив мода, Font Fixer, комплект и файлы SHA-256. Оригинальная игра доступна по ссылке в README.
