Русская локализация Gardendless **0.16.27** на основе перевода KRUTONIK. Мод **1.3.1**, Font Fixer **1.42**, кириллические шрифты **0.5**.

Оригинальная игра — https://github.com/Gzh0821/pvzg_site/releases/tag/0.16.27

Исходный русификатор — https://github.com/KRUTONIK/pvz2-gardendless-russian

### Изменения

- Переведены новые диалоги Смоломёта, тексты колод, ошибки загрузки и условие уровня Водной лозы. В пакете 7566 русских полей.
- Перевод новых окон «Об игре», «Обновления», встроенных элементов окон уровней сообщества и музыкальных наборов.
- Сохранены прежние исправления интерфейса и шрифты. Пользовательские названия и описания уровней не подменяются.

### Установка

1. Скачайте игру **0.16.27** по ссылке выше.
2. Распакуйте комплект `with_Font_Fixer` или скачайте мод и помощник отдельно.
3. Запустите Font Fixer **1.42**, выберите `pvzge-0.16.27.exe` и запустите игру через помощник.
4. Через **F9 → Mods → Import ZIP** импортируйте `PvZ2_Gardendless_Russian_0.16.27_preview.zip`, примените мод и выберите русский язык.

**Даже если мод 1.3.0 уже установлен, для игры 0.16.27 нужен импорт нового пакета 1.3.1.** Внешний архив `with_Font_Fixer` не является модом — импортируйте вложенный `preview.zip`.

### Проверки

Пройдены 9 проверок пакета, 66 JavaScript-проверок помощника, Go test/vet и проверки ZIP. Новые окна проверены в отдельном Chromium-стенде. Snapshot-loader 0.16.27 проверен изолированно с unzip из 0.16.15, без запуска игрового bootstrap. Файлы `.sha256` содержат контрольные суммы загрузок.

Содержимое изолированного окна назначения клавиш остаётся на языке игры; переводится его заголовок. Игра, GUI помощника и импорт при автоматических проверках не запускались. Визуальная проверка в игре выполняется пользователем.

Предварительный выпуск адаптации.
