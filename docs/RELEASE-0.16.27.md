# Подготовка локализации Gardendless 0.16.27

Оригинальная игра: https://github.com/Gzh0821/pvzg_site/releases/tag/0.16.27

Исходный перевод: https://github.com/KRUTONIK/pvz2-gardendless-russian

Мод 1.3.1, Font Fixer 1.42, JS VERSION 47, собственные шрифты 0.5.
Тег и GitHub Release не создаются без отдельного одобрения владельца.

## Изменения

По сравнению с 0.16.15 в оригинале добавлены девять уровней Водной лозы и изменены семь JSON-файлов. Переведены новые реплики Смоломёта, тексты колод, ошибки загрузки уровней и условие запрета посадки на лавовых озёрах. Пакет содержит 308 файлов данных, манифест и 7566 русских полей. Пропущенных переводов нет. Данные, не относящиеся к переводу, и порядок массивов совпадают с оригиналом 0.16.27.

Помощник поддерживает новые нативные DOM-окна. Документы «Об игре» и «Обновления» распознаются по полному тексту; сохранены авторы, клавиши и ссылки. В окнах сообщества и музыкальных наборов переводятся встроенные элементы управления. Названия, описания, пути и авторы пользовательских уровней, значения поисковой строки и обработчики кнопок сохраняются. Отключение перевода, смена языка и завершение помощника восстанавливают исходные подписи. Поддержка старых iframe-документов сохранена.

Прежние сдвиги «Продолжить», «Зажжём!», оформление пиньят, таймеров и семейств не менялись. Оригинальные TTF не изменились. Содержимое изолированного iframe назначения клавиш не переводится; переводится заголовок его окна.

## Проверка и установка

Пройдены 66 JS-проверок помощника, 9 проверок пакета, Go test/vet, проверка целостности обоих ZIP. Отдельный Chromium-стенд проверяет оба документа на английском и китайском, восстановление оригинала, неизменность пользовательских данных, поиска и обработчиков. Загрузчик snapshot 0.16.27 проверен изолированно: его импорт из игрового bootstrap заменён самостоятельным unzip из поставки 0.16.15. Сам bootstrap и игра для проверки не запускаются.

Игра, GUI помощника и импорт агентом не запускаются; сохранения и настройки не меняются. Окончательный вид и импорт проверяет пользователь. Для 0.16.27 нужен новый импорт мода 1.3.1 даже при установленном 1.3.0. В F9 → Mods → Import ZIP выбирайте внутренний `PvZ2_Gardendless_Russian_0.16.27_preview.zip`; внешний `with_Font_Fixer` сначала распакуйте. Запускайте `pvzge-0.16.27.exe` через помощник 1.42.

## Сборка в рабочем окружении

Основные исходники помощника — `font-fixer/`, редакторские переводы — `localization/0.16.27/`. `translations.json` содержит проверяемые исходные en/zh вместе с ru; изменение источника не должно молча применять старый перевод.

Сборщики пока используют соседний `pvz2-localization-research` и его оригиналы, восстановленные базы, старые переводы, Go 1.27.3, Node 26.10.0, 7-Zip 24.05 и Playwright 1.56.1. Это не самостоятельная сборка из одного клона. Оригинальные EXE, извлечённые игровые ресурсы, сохранения и инструменты в Git не включаются.

Обновлённые сценарии и проверки сохранены в `build-tools/research/` с той же структурой, что у проекта исследования. Перед сборкой перенесите их в исследовательский проект, перенесите `font-fixer/` в его `src/font-fixer/`, а переводы и UI-словарь — в `assets/translations-0.16.27.json` и `assets/ui-translations-0.16.27.json`. Документы сборщик читает непосредственно из `localization/0.16.27/documents/` этого форка.

Из `C:\Users\sonar\projects\pvz2-localization-research`:

```powershell
node scripts/build-patch.cjs 0.16.27
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-font-fixer.ps1 -Version 0.16.27
node scripts/check-native-dialogs.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-patch.ps1 -Version 0.16.27
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-bundle.ps1 -Version 0.16.27
node scripts/check-import.cjs 0.16.27
```

Артефакты и SHA-256 находятся в `dist/`. Перед упаковкой сравните исходники и сгенерированные JSON помощника между форком и исследовательским проектом. Локальный деплой готовых артефактов разрешён в `E:\TGames\pvzge`; он не включает запуск игры и импорт. Контрольные суммы поставки — `SHA256SUMS-0.16.27.txt` рядом с этой документацией.
