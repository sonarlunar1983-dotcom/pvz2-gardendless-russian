# Подготовка локализации Gardendless 0.16.31

Игра: https://github.com/Gzh0821/pvzg_site/releases/tag/0.16.31

Исходный перевод: https://github.com/KRUTONIK/pvz2-gardendless-russian

Мод **1.3.2**, Font Fixer **1.43**, JS VERSION **48**, шрифты **0.5**. Рабочая ветка `localization/0.16.31`. Тег и GitHub Release не создаются без отдельного одобрения владельца.

## Что изменилось относительно 0.16.27

В оригинале добавлены 70 ежедневных уровней и изменены 10 JSON-файлов. Новое растение Headbutter Lettuce переведено как «Масляный салат», включая Альманах. Переведены новые события пиньят, сообщения выживания, реплики, названия колод Водной лозы. Изменения баланса и порядок массивов сохранены. Новый пакет содержит 322 файла данных, манифест и 7638 русских полей. 66 полей потребовали нового проверенного перевода; пропусков нет. Остальные переводы перенесены с проверкой исходного текста и контекста.

Шрифты оригинала по содержимому прежние: появились дополнительные копии FBUSV8C5EI под именами Game Default/Default.ttf. Движок Cocos отличается только CRLF/LF. Игровые классы и поля, используемые помощником, проверены.

Окно GitHub теперь имеет новую разметку, кнопки собственного уровня, репозитория, запуска, возврата, путь и статусы загрузки/победы. Помощник переводит встроенные подписи; пользовательские имена, пути, описания и авторы остаются исходными. Сохраняются поиск, голосование, иконки и обработчики. Даты и числовой прогресс не меняются. Для русских DOM-окон используется Segoe UI вместо Game Default без кириллицы; при отключении восстанавливаются исходные свойства шрифта без изменения трансформации окна.

Переведены пять пунктов обновлений и актуальное окно «Об игре»: добавленный автор и все ссылки на авторов сохранены. Поддержка старых документов и все прежние правки «Продолжить», «Зажжём!», пиньят, таймеров и семейств сохранены. Содержимое sandbox-окна назначения клавиш не переводится; переводится заголовок.

## Проверки и ограничения

66 JS-проверок помощника, 10 проверок пакета, Go test/vet, целостность обоих ZIP. Проверены оба документа en/zh и старая поддержка iframe. Chromium-стенд проверяет новые элементы GitHub, неизменность пользовательского содержимого и поиска, работу обработчиков и голосования, обновление статуса, восстановление текста и шрифта, сохранность трансформации окна. PNG просмотрены. Это отдельный стенд, а не запуск игры.

Из нового JS-бандла через Acorn и eslint-scope извлекаются только декларации диалога и Markdown с зависимостями. Импорты игрового runtime и bootstrap запрещены проверкой. Новый snapshot-loader также проверяется изолированно с самостоятельным unzip из 0.16.15. Ни исходный бандл игры, ни EXE для теста не запускаются.

Игра, GUI помощника и импорт агентом не запускаются; сохранения и настройки не меняются. Окончательный вид и импорт проверяет пользователь.

## Установка

Нужна игра **0.16.31**. Запустите её через `PvZ2_Gardendless_Font_Fixer_1.43.exe`. В **F9 → Mods → Import ZIP** импортируйте `PvZ2_Gardendless_Russian_0.16.31_preview.zip`, примените мод 1.3.2 и выберите русский язык. Новый импорт нужен даже при установленном 1.3.1. Внешний архив `with_Font_Fixer` сначала распакуйте: он не является модом.

## Сборка в рабочем окружении

Основной код — `font-fixer/`, редакторские переводы и документы — `localization/0.16.31/`. В `translations.json` рядом с ru сохранены точные исходные en/zh. Обновлённые сборщики и проверки — `build-tools/research/`.

Как и в 0.16.27, сборка требует соседнего `pvz2-localization-research` с оригиналами, восстановленными базами, прежними переводами и инструментами. Проверены Node 26.10.0, Go 1.27.3, 7-Zip 24.05, Playwright 1.56.1. Это не автономная сборка из одного клона.

Перенесите снимок `build-tools/research/` в проект исследования, код помощника — в его `src/font-fixer/`, новые словари — в `assets/translations-0.16.31.json` и `assets/ui-translations-0.16.31.json`. Документы сборщик читает прямо из форка. Перед упаковкой сверяйте код и сгенерированные JSON помощника с форком.

Для анализа JS скопируйте манифесты `build-tools/analysis-dependencies/` в `pvz2-localization-research/tools/code-analysis/` и из корня исследования выполните:

```powershell
npm ci --prefix tools/code-analysis --no-audit --no-fund
node scripts/build-patch.cjs 0.16.31
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-font-fixer.ps1 -Version 0.16.31
node scripts/check-native-dialogs.cjs 0.16.31
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-patch.ps1 -Version 0.16.31
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-bundle.ps1 -Version 0.16.31
node scripts/check-import.cjs 0.16.31
```

После создания `deployment-0.16.31.json` локальный деплой выполняется командой `node scripts/deploy-0.16.31.cjs`. Скрипт сначала проверяет все исходные хеши, затем копирует только три готовых артефакта и их .sha256 и проверяет копии.

Файлы и SHA-256 — в `dist/`; локальный деплой разрешён в `E:\TGames\pvzge`. Контрольные суммы — [SHA256SUMS-0.16.31.txt](SHA256SUMS-0.16.31.txt). Оригинальные EXE, извлечённые ресурсы, сохранения, инструменты и учётные данные в Git не включаются.
